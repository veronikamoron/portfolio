# Security Policy

## Architecture & Privacy Posture
This portfolio (`https://veronikamoron.github.io/portfolio/`) is a **purely static client-side website** hosted on GitHub Pages:
- **No backend, no database, no API keys, and no server-side secrets.**
- **No cookies, no analytics trackers, and no third-party telemetry** (aside from Google Fonts stylesheet loading).
- **No sensitive personal data** (such as phone numbers, home addresses, or private credentials) is stored in this repository.

## Reporting a Security or Privacy Issue
If you discover a security vulnerability, broken external redirect, or accidental exposure of sensitive information in this repository, please report it responsibly by emailing:

- **Contact:** `veronika@moron.de`
- **Subject:** `[Security] veronikamoron/portfolio`

Please do not open a public GitHub issue for sensitive findings. Reports will be reviewed and addressed promptly.
